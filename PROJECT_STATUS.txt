1. WHAT IS CLOUDVAULT
================================================================================

CloudVault is a multi-tier cloud storage platform that automatically moves
files between storage tiers based on how old they are — similar to how
enterprise systems like AWS S3 Lifecycle or Google Cloud Storage Nearline work.

Files start in the fastest storage (Hot), and as they age, the system
automatically migrates them to cheaper, slower storage (Warm → Archive).


2. TECH STACK
================================================================================

Backend:
  - Python 3 + FastAPI (REST API framework)
  - SQLAlchemy ORM + SQLite database
  - Pydantic v2 (request/response validation)
  - Celery (background task engine, running in eager/sync mode)
  - bcrypt (password hashing)
  - JWT (stateless authentication tokens)

Frontend:
  - React 18 + Vite (build tool)
  - Tailwind CSS (styling)
  - Lucide React (icon library)
  - Axios (HTTP client)
  - React Router DOM (navigation)

Storage Backends:
  - MinIO          → Hot Tier   (fast, frequently accessed files)
  - SeaweedFS      → Warm Tier  (medium speed, less accessed files)
  - Scality S3     → Archive Tier (cold storage, rarely accessed files)
